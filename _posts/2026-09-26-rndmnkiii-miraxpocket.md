Mirax Pocket Core
=================

This core is a completely experimental project employing a hybrid method for 
FPGA implementation. Given the game's rarity, obtaining an original PCB is 
virtually impossible, so alternative sources must be sought to infer its 
operation. 
We are starting with the MAME driver's C++ code and existing HDL implementations 
of both the Z80 processor and the two GI AY-3-8912 sound chips. High-resolution 
images of both sides of the PCB are available to help trace the circuit paths 
between the ICs and infer the system's functionality. This process will be 
iterative and AI-assisted.
