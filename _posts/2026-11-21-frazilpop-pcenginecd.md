PC Engine CD-ROM² / TurboGrafx-CD core with save states.

Built from Mazamars312's openfpga-pcengine-cd, itself based on agg23's PC Engine port, with the chips from MiSTer's TurboGrafx16 core by Gregory Estrade, srg320, greyrogue and dshadoff. The MiSTer CD drive run as firmware on a small RISC-V CPU inside the core.
Analogue Pocket core by Frazilpop.
