Interton VC 4000 for Analogue Pocket.

Port of the MiSTer VC4000 core (Signetics 2650 CPU and 2636 video
chip). Also runs games for the compatible consoles, such as the
Acetronic MPU-1000 and Occitane OC2000.

No BIOS needed. Cartridges: .bin (up to 8 KB) in Assets/vc4000/common.

Controls
  A Fire (key 2)    B Key 1     X Key 3     Y Key 0
  L Clear           R Enter     Start Start
  Select tap        Game Select
  Hold Select:  X=4 Y=5 A=6 B=7 Up=8 Right=9
  Dock L2           Game Select

The original joysticks are analog. A Dock controller's left stick
works as one. With the D-pad, choose Absolute (jumps to the edges) or
Gradual (moves step by step) in the core settings.

Runs at the original 50 Hz PAL speed.
