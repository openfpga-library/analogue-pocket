Atari 7800 ProSystem for Analogue Pocket
Ported from the MiSTer Atari7800 core by Jamie Blanks (Kitrinx),
with thanks to its contributors. See the project README for full credits.

Cartridges: .a78 (with header), .a26 / .bin (2600).
Firmware (all optional, in /Assets/7800/common/):
  7800bios.bin      7800 BIOS; turn off "Skip BIOS" to boot through it
  highscor.rom      High Score Cartridge firmware (4 KiB), needed for the HSC;
  or hsc.a78        the same firmware with an A78 header
  supercharger.bin  Starpath Supercharger BIOS (2 KiB), for 2600 SC games

Controls: A/Y left button, B/X right button, L pause (2600: colour/B&W),
Select, Start = Reset.

Saves: the High Score Cart and the SaveKey (port 2) each keep one shared
file for all games, hsc.sav and savekey.sav.

https://github.com/Miasmark/openFPGA-7800
