Nokia N-Gage

The phone's own firmware (Symbian OS 6.1)
runs on a soft ARMv4T in the FPGA, above
a small kernel in place of the phone's,
with the game's memory card as drive E:.

Needs your own firmware dump and game
cards: see Assets/ngage/common/README.txt

* d-pad    the phone's arrows
* A / B    game keys 5 / 7
* X        OK, Y key 9
* L / R    the soft keys
* Select   #, Start OK

Analogizer: CRT video and SNAC pads,
set in this core's menu (Analogizer:
On; H and V Position centre the
picture). The slot is powered: remove
any cartridge first.
