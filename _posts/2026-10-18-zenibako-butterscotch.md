Butterscotch Pocket (unofficial)

Butterscotch, an open-source GameMaker
runner by MrPowerGamerBR, on openfpgaOS.
It runs Undertale v1.08 and, as an
experiment, Deltarune Chapter 1. You
need to provide your own game files.

Put in Assets/butterscotch/common:
  data.win      from your game
  textures.bin  built from data.win
  music.bin     built from data.win
Deltarune: deltarune.win,
  dr_textures.bin, dr_music.bin

Controls
  D-pad    Move
  A/Start  Confirm
  B        Cancel
  X or Y   Game menu
  Select   Butterscotch menu
  L        Toggle speed/accuracy
           (starts in speed)

Select > Debug:
  Save log to SD card comes first.
  Save-state status checks whether
  the current scene can be saved.
  Enable debug buttons for:
  R           Log overlay
  Hold Select and press:
  Right/Left  Next/previous room
  Start       Pause on/off
  A           Step a frame (paused)
  B           Unstick (interact = 0)
  X           Script times in the log
  Y           Save the log to the card

Starting takes about 20 seconds.
After saving the log, quit through the
Analogue menu to keep the log.
