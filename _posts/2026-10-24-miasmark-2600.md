Atari 2600 (VCS) for Analogue Pocket
The TIA, RIOT, 6507 and 2600 mappers come from the MiSTer Atari7800 core
by Jamie Blanks (Kitrinx), through the openFPGA-7800 port. See the
project README for full credits.

Cartridges: .a26 / .bin, mapper detected automatically (Mapper menu to
force one). DPC+/CDF/CDFJ/CDFJ+ run on the core's own ARM (DARIA).
.a78 (7800) images are refused.
Firmware (optional, in /Assets/2600/common/):
  supercharger.bin  Starpath Supercharger BIOS (2 KiB). Without it the
                    core loads Supercharger games itself.

Controls: A fire, X fire (repeats with Turbo), B the paddle button or
trigger (a joystick has none), L colour/B&W, Select, Start = Reset.
Port 1 and 2 Input: joystick, paddles, driving, light gun; port 1 also
dual stick and Booster Grip. Set by hand per game.

Saves: one shared file each for all games: savekey.sav (SaveKey on
port 2, 32 KiB; menu SaveKey = On) and fa2.sav (FA2 cartridges such as
Star Castle Arcade, 256 bytes). 7800-core users can copy savekey.sav
over from the 7800's save folder.
