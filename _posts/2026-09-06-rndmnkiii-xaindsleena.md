Xain'd Sleena Pocket Core (Technos Japan Corp. 1986) by RndMnkIII
-----------------------------------------------------------------

This core comes from the MiSTer FPGA original implementation that I did 
in 2022. Is based in a bootleg board and PCB schematics. The MC68705P5 protection MCU 
is implemented (using José Tejada @topapate jt68x5 core) and supports the protected romsets.

The Analogizer support includes several types of natives game controllers and PS/2 keyboards
usign a specific PS/2 SNAC adapter.

Check the Analogizer wiki: https://github.com/RndMnkIII/Analogizer/wiki
