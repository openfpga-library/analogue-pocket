PlayStation core for Analogue Pocket, by GuardianSoul. A general PlayStation core built on the MiSTer PSX core.

You need your own BIOS (for example Assets/playstation/common/scph5501.bin) and your own games; none are included. Put each game in its own folder in Assets/playstation/common, then make its game file with the PlayStation game files plugin in pupdate or Pocket Sync. You can also press Back in the game list and pick a game's .cue.

See the README for setup, controls, multi-disc games and memory cards. Source code, credits and licenses: https://github.com/GuardianSoul/openfpga-PlayStation. The core is GPL-2.0; see the licenses folder.
